## 💬 &nbsp; What is VibeSpace?

</div>

> **VibeSpace** is a fully animated interactive emotional wellness playground where every click, cursor move, and mood choice explodes into life. It transforms how you express and explore emotions — not with boring charts or clinical forms, but through **living characters**, **dynamic mood worlds**, **particle effects**, and **pure animated chaos**.
>
> No frameworks. No installs. No cost. Just one `index.html` file that hits different. ✨

## 🚀 &nbsp; Getting Started

</div>

<br/>

### Option 1 — Just open it (simplest)

```bash
# No installation needed at all!
# Download index.html → double-click → opens in browser
```

### Option 2 — VS Code + Live Server (recommended for development)

```bash
# 1. Open VS Code
# 2. File → Open Folder → select VibeSpace folder
# 3. Right-click index.html in Explorer
# 4. Click "Open with Live Server"
# 5. Browser opens at http://127.0.0.1:5500 ✨
```

### Option 3 — Clone and run

```bash
# Clone the repo
git clone https://github.com/YOURUSERNAME/vibespace.git

# Go into the folder
cd vibespace

# Open with Live Server in VS Code OR just open index.html directly
```

## 🌐 &nbsp; Deployment — Live on Vercel

</div>

<br/>

VibeSpace is deployed for **free** on [Vercel](https://vercel.com). Here's how it was done:

```bash
# Step 1 — Initialize git in the project folder
git init
git add .
git commit -m "VibeSpace launch 🚀"

# Step 2 — Push to GitHub
git branch -M main
git remote add origin https://github.com/YOURUSERNAME/vibespace.git
git push -u origin main

# Step 3 — Go to vercel.com → Import GitHub repo → Deploy
# Your live URL appears in 30 seconds! 🎉
```

**Auto-deploy** is enabled — every `git push` to `main` triggers a new deployment automatically.
